18.10 — Testing

Test your Capstone application systematically, identify defects, fix problems, verify functionality, and document the final results.

🎯 Learning Objectives

  • Create a structured testing plan for the Capstone.
  • Test front-end functionality.
  • Test back-end functionality.
  • Test database operations.
  • Test authentication and authorization.
  • Test forms and user input.
  • Test responsive behavior.
  • Test accessibility.
  • Identify, document, and prioritize defects.
  • Fix identified defects.
  • Perform regression testing.
  • Document final testing results.

📖 1. What Is Software Testing?

Software testing is the process of evaluating an application to determine whether it behaves as expected and satisfies its requirements.

Testing should happen throughout development rather than only immediately before submission.

Capstone Testing Goal

Your goal is not simply to prove that the application works when everything goes perfectly. You should also test what happens when users enter incorrect information, leave fields empty, navigate unexpectedly, use unsupported input, or attempt actions they should not be allowed to perform.
