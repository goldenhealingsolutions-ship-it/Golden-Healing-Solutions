Lesson Concept 01

What Is Web Development?

Web development is the process of creating, building, testing, deploying, maintaining, and improving websites and web applications.

Web development combines programming, markup languages, styling, databases, server technologies, user interfaces, security, accessibility, testing, and deployment.

When you visit a website, there may be many different technologies working together to produce what you see and interact with.

KEY CONCEPT Web development is not just "writing code." It is the process of creating functional digital experiences that users can access and interact with through the web.
Real-World Example

Imagine that Golden Healing Solutions wants to create a website where students can register for a bootcamp.

Someone has to design the experience. Someone has to build the webpage. Someone has to make the forms work. Someone may need to store student information. Someone needs to test the system. Someone needs to deploy and maintain it.

Those responsibilities represent different parts of the web development process.

Lesson Concept 02

What Is a Website?

A website is a collection of web pages and related resources that users can access through the internet using a web browser.

A website can contain text, images, videos, audio, navigation links, forms, documents, animations, and interactive elements.

Websites are commonly accessed through a domain name or web address.

THINK OF IT THIS WAY A website is like a digital location. Just as a physical business has an address that customers can visit, a website has a web address that users can enter into a browser.

What Happens When You Visit a Website?

Suppose you enter a website address into your browser.

BASIC WEB REQUEST
1. USER You enter a website address or click a link.
2. WEB BROWSER Your browser sends a request for the requested resource.
3. SERVER A server processes the request and provides the necessary resources.
4. RESPONSE The browser receives the response and renders the webpage for the user.
Lesson Concept 03

What Is a Web Application?

A web application is an interactive application that users access through a web browser.

Instead of simply displaying information, a web application allows users to perform actions and interact with data or functionality.

Examples include:

  • Online banking
  • Email applications
  • Online learning platforms
  • Project management software
  • Job boards
  • E-commerce systems
  • Social media platforms
  • Customer portals
IMPORTANT The distinction between a website and a web application is not always absolute. Modern websites frequently contain interactive application features.

🌐 WEBSITE

  • Presents information
  • Provides navigation
  • Displays text and media
  • May contain forms
  • May contain interactive features

💻 WEB APPLICATION

  • Provides interactive functionality
  • Processes user actions
  • Often works with stored data
  • May require user authentication
  • Often behaves more like software

Lesson Concept 04

Front-End Development

Front-end development focuses on the part of a website or web application that users see and interact with.

The front end is sometimes called the client side because much of the code is executed in the user's web browser.

Core Front-End Technologies

Technology Purpose Example
HTML Provides structure and meaning Headings, paragraphs, forms
CSS Controls presentation and layout Colors, spacing, responsive layouts
JavaScript Adds programming behavior Buttons, validation, dynamic content
EASY MEMORY TRICK HTML = Structure
CSS = Appearance
JavaScript = Behavior
Lesson Concept 05

Back-End Development

Back-end development focuses on the server-side systems that power an application.

Users typically do not see the back-end code directly.

Back-end systems may handle:

  • Application logic
  • User authentication
  • Database operations
  • APIs
  • Data processing
  • Security
  • Server-side validation
  • Business rules

Common Back-End Technologies

Developers can use many different programming languages and technologies on the back end.

Technology Common Use
JavaScript / Node.js Server-side JavaScript applications
Python Web applications, APIs, automation, data-related applications
Java Enterprise applications and large-scale systems
C# Microsoft-based application development and web systems
PHP Server-side web development

Databases

Many web applications need a way to store information.

A database can store information such as customer accounts, products, orders, course progress, messages, or other application data.

Examples include:

  • MySQL
  • PostgreSQL
  • Microsoft SQL Server
  • MongoDB
Lesson Concept 06

Full-Stack Development

Full-stack development refers to working across multiple layers of a web application, including both front-end and back-end development.

A full-stack developer understands how the user interface connects to server-side application logic and data.

THE WEB APPLICATION STACK
FRONT END HTML • CSS • JavaScript • User Interface
BACK END Server • APIs • Business Logic • Authentication
DATA LAYER Databases • Stored Information • Data Operations
REMEMBER Full-stack does not mean "expert in every technology." It means having the ability to work across multiple layers of a web application and understand how those layers communicate.
Lesson Concept 07

Web Developer vs. Web Designer

🎨 WEB DESIGNER

Typically focuses on how a website looks, feels, and communicates with users.

  • Visual design
  • Typography
  • Color systems
  • Layout
  • User experience
  • User interface design
  • Prototypes
  • Design systems

💻 WEB DEVELOPER

Typically focuses on building the functional website or application.

  • HTML
  • CSS
  • JavaScript
  • Programming
  • APIs
  • Databases
  • Testing
  • Deployment

Do Developers and Designers Ever Overlap?

Yes. Modern technology professionals frequently develop skills that cross traditional job boundaries.

A developer may understand user experience and visual design. A designer may understand HTML and CSS. A smaller company may even expect one person to handle both design and development.

CAREER TIP Understanding both design and development can make you a stronger technology professional because you can communicate effectively with designers, developers, clients, and stakeholders.

Lesson Concept 09

How Everything Works Together

Let's put everything together using an online learning platform as an example.

A student opens the learning platform in a browser.

The front end displays the dashboard, lessons, buttons, videos, quizzes, and navigation.

The student clicks: "Start Lesson."

JavaScript can respond to the interaction in the browser. The application may then communicate with the back end.

The back end can process the request and retrieve information from a database.

The server can return the necessary information.

The front end then updates the interface for the student.

THE BIG PICTURE User → Browser → Front End → Back End → Database → Back End → Front End → User
