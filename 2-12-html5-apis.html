2.12 — HTML5 APIs

Learn how HTML5 APIs allow webpages to interact with browser features, store information, work with multimedia, draw graphics, respond to user actions, and create more interactive web applications.

🎯 Learning Objectives

By the end of this lesson, you should be able to:

  • Define an API and explain what a web API does.
  • Explain the difference between HTML elements and browser APIs.
  • Understand the purpose of the DOM API.
  • Use JavaScript to interact with HTML elements.
  • Understand the Web Storage API.
  • Explain localStorage and sessionStorage.
  • Understand the Canvas API.
  • Understand the Geolocation API and its permission requirements.
  • Understand basic multimedia APIs.
  • Understand browser APIs such as Fetch.
  • Understand that browser API availability can vary by environment.
  • Apply HTML5 APIs in a simple web project.

📖 1. What Is an API?

API stands for Application Programming Interface.

An API provides a defined way for different pieces of software to communicate with each other or access functionality.

In web development, browser APIs allow JavaScript to interact with browser features and webpage content.

Simple way to think about it:

An API is like a set of instructions that tells your program how it can request or use a particular service or capability.

🌐 2. What Are HTML5 APIs?

HTML5 introduced and standardized many capabilities that allow web applications to become more interactive and powerful.

🌳 DOM API

Allows JavaScript to access and manipulate the document structure.

💾 Web Storage API

Allows webpages to store data in the browser.

🎨 Canvas API

Allows JavaScript to draw graphics inside a canvas element.

📍 Geolocation API

Allows a website to request the user's geographic location.

🎥 Media APIs

Provide functionality for working with audio and video.

🌐 Fetch API

Allows JavaScript to make network requests.

🌳 3. DOM API

The Document Object Model (DOM) represents an HTML document as a structure that JavaScript can access and manipulate.

HTML 
<h1 id="welcome">
    Welcome to the Bootcamp
</h1>
JavaScript 
const heading =
    document.getElementById("welcome");

heading.textContent =
    "Welcome, Web Developer!";
Result:

JavaScript finds the HTML element and changes its text.

🔎 4. Selecting HTML Elements

JavaScript provides several methods for selecting elements. 

document.getElementById("title");

document.querySelector(".card");

document.querySelector("#main");

document.querySelectorAll("p");

The DOM API is one of the most important browser APIs for front-end development.

🖱️ 5. Events and the DOM

Browser events allow JavaScript to respond when users interact with a webpage. 

const button =
    document.getElementById("myButton");

button.addEventListener(
    "click",
    function() {

        alert("Button clicked!");

    }
);

Common events include:

  • click
  • submit
  • change
  • input
  • keydown
  • mouseover
  • load

💾 6. Web Storage API

The Web Storage API provides browser-based storage through localStorage and sessionStorage.

localStorage

Data generally remains available after the browser is closed and reopened, until it is removed.

sessionStorage

Data is associated with the current browser tab/session and is generally cleared when that page session ends.

💾 7. localStorage

You can store a value using setItem(). 

localStorage.setItem(
    "studentName",
    "Jordan"
);

Retrieve the value with getItem(). 

const name =
    localStorage.getItem(
        "studentName"
    );

console.log(name);

Remove an item using: 

localStorage.removeItem(
    "studentName"
);

🕐 8. sessionStorage 

sessionStorage.setItem(
    "lesson",
    "2.12"
);

const lesson =
    sessionStorage.getItem(
        "lesson"
    );

console.log(lesson);
Important:

Web Storage stores strings. When working with objects or arrays, you can use JSON.stringify() and JSON.parse() to convert data.

🗃️ 9. Storing Objects 

const student = {

    name: "Jordan",
    course: "Web Development",
    progress: 85

};


localStorage.setItem(
    "student",
    JSON.stringify(student)
);

To retrieve the object: 

const savedStudent =
    JSON.parse(
        localStorage.getItem(
            "student"
        )
    );

console.log(
    savedStudent.name
);

🎨 10. Canvas API

The Canvas API allows JavaScript to draw graphics, shapes, images, and other visual content inside a <canvas> element. 

<canvas
    id="myCanvas"
    width="400"
    height="200">
</canvas>

JavaScript can access the drawing context. 

const canvas =
    document.getElementById(
        "myCanvas"
    );

const ctx =
    canvas.getContext("2d");

ctx.fillRect(
    50,
    50,
    150,
    75
);

📍 12. Geolocation API

The Geolocation API can allow a website to request the user's geographic location. 

navigator.geolocation.getCurrentPosition(

    function(position) {

        console.log(
            position.coords.latitude
        );

        console.log(
            position.coords.longitude
        );

    }

);
Privacy and permission:

Browsers generally require the user to grant permission before a website can access their location. Never assume that a website automatically has access to a user's location.

🌐 14. Fetch API

The Fetch API allows JavaScript to make network requests and work with responses. 

fetch("https://example.com/data.json")

    .then(response =>
        response.json()
    )

    .then(data => {

        console.log(data);

    })

    .catch(error => {

        console.error(error);

    });

Fetch is commonly used to communicate with web services and APIs.

🎥 15. Audio and Video APIs

HTML provides native multimedia elements such as <audio> and <video>. 

<video
    id="courseVideo"
    controls
    width="600">

    <source
        src="lesson.mp4"
        type="video/mp4">

</video>

JavaScript can interact with media elements. 

const video =
    document.getElementById(
        "courseVideo"
    );

video.play();

video.pause();

🖱️ 16. Drag and Drop

Browser drag-and-drop functionality can allow users to move elements or files through a webpage interface. 

<div
    draggable="true"
    id="dragItem">

    Drag Me

</div>

JavaScript can listen for events such as:

  • dragstart
  • dragover
  • drop
  • dragend

🕘 17. History API

The History API allows JavaScript to interact with the browser's session history. 

history.back();

history.forward();

history.go(-1);

Modern web applications can also use methods such as pushState() to update browser history without performing a traditional full-page navigation.

📋 18. Clipboard API

The Clipboard API can be used to interact with clipboard data, subject to browser security and permission rules. 

navigator.clipboard.writeText(
    "Hello from the Web Development Bootcamp!"
);
Security reminder:

Clipboard access can be restricted by browsers and usually requires a secure context and appropriate user interaction.

🔔 19. Browser Notifications

Some browsers provide a Notifications API that allows websites to request permission to display notifications. 

Notification.requestPermission()
    .then(permission => {

        if (permission === "granted") {

            new Notification(
                "Lesson Complete!"
            );

        }

    });
Important:

Users must control whether websites can send notifications. Browser support, security requirements, and permissions apply.

🔐 20. APIs, Security & Privacy

Browser APIs can provide access to powerful capabilities. Developers must consider security and privacy.

  • Request only the permissions you actually need.
  • Explain why a permission is needed.
  • Do not expose sensitive information unnecessarily.
  • Validate data received from external sources.
  • Use secure connections when required.
  • Respect browser security restrictions.
Never assume that an API gives unrestricted access.

Modern browsers use permissions, security policies, and other restrictions to protect users.

🌎 21. Browser Compatibility

Not every browser or environment supports every API in exactly the same way.

Professional developers should verify API support before relying on a browser feature. 

if ("geolocation" in navigator) {

    console.log(
        "Geolocation is available."
    );

} else {

    console.log(
        "Geolocation is not available."
    );

}

⭐ 23. Key Concepts to Remember

DOM

Used to access and manipulate webpage content and structure.

localStorage

Stores browser data that can persist between sessions.

sessionStorage

Stores data for the current page session.

Canvas

Provides a drawing surface controlled through JavaScript.

Geolocation

Allows a site to request geographic location with permission.

Fetch

Makes network requests from JavaScript.
