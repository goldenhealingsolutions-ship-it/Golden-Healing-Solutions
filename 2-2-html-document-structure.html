2.2 — HTML Document Structure

Learn how HTML documents are organized and how the browser interprets the structure of an HTML page.

🎯 Learning Objectives

By the end of this lesson, you should be able to:

  • Explain the basic structure of an HTML document.
  • Explain the purpose of the DOCTYPE declaration.
  • Identify the HTML root element.
  • Explain the purpose of the head section.
  • Explain the purpose of the body section.
  • Use metadata correctly.
  • Create an HTML document using proper structure.
  • Understand the relationship between HTML elements.
  • Explain the difference between page metadata and visible content.

📖 1. Understanding HTML Document Structure

An HTML document follows a standard structure that allows web browsers to correctly interpret and display the page.

Although HTML pages can contain many different elements, most HTML documents begin with the same basic structure.

Think of an HTML document like a blueprint.

The structure tells the browser where the document begins, where its metadata belongs, and where the content users see should be placed.

🏗️ 2. The Basic HTML5 Structure

Standard HTML5 Document 
<!DOCTYPE html>

<html lang="en">

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>My Web Page</title>

</head>

<body>

    <h1>Welcome to My Website</h1>

    <p>
        This is the content of my web page.
    </p>

</body>

</html>
<!DOCTYPE html>
  ↓
<html>
  ↓
    <head>
      Metadata
      Title
      Stylesheets
    </head>
  ↓
    <body>
      Headings
      Paragraphs
      Images
      Links
      Forms
    </body>
</html>

📌 3. The DOCTYPE Declaration 

<!DOCTYPE html>

The <!DOCTYPE html> declaration tells the browser that the document should be interpreted using the HTML5 standard.

It appears at the very beginning of an HTML document.

Important:

DOCTYPE is a declaration, not a normal HTML element. It does not appear as visible content on the page.

🌳 4. The HTML Root Element 

<html lang="en">

    ...

</html>

The <html> element is the root element of the HTML document. Every other HTML element is contained within it.

What does lang="en" mean?

The lang attribute identifies the primary language of the document. For example: 

<html lang="en">

This tells browsers and assistive technologies that the document is written primarily in English.

🧠 5. The Head Section 

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>My Website</title>

</head>

The <head> contains information about the document that is generally not displayed directly as page content.

Element Purpose
<title> Defines the document title shown in the browser tab.
<meta> Provides metadata about the document.
<link> Connects external resources such as stylesheets.
<style> Contains CSS rules within the document.
<script> Loads or contains JavaScript.

⚙️ 6. Metadata

Metadata is information about the document rather than the main visible content.

Character Encoding 

<meta charset="UTF-8">

UTF-8 supports a very large range of characters and is the standard character encoding commonly used for modern web pages.

Responsive Viewport 

<meta
    name="viewport"
    content="width=device-width, initial-scale=1.0">

This helps the page display properly on different screen sizes and is important for responsive design.

🏷️ 7. The Title Element 

<title>
    Web Development Bootcamp
</title>

The <title> element specifies the document title displayed by the browser.

Best Practice:

Use a clear and descriptive title that tells users what the page is about.

👁️ 8. The Body Section 

<body>

    <h1>My Website</h1>

    <p>
        Welcome to my website.
    </p>

</body>

The <body> contains the content that users see and interact with on the web page.

Content Examples
Text Headings, paragraphs, lists
Media Images, audio, video
Navigation Menus and links
Forms Inputs, buttons, forms
Interactive content Buttons and application components

🪆 9. Parent & Child Elements

HTML elements can contain other elements. The containing element is called the parent. The element inside it is called the child. 

<section>

    <h2>About Our Company</h2>

    <p>
        We provide professional services.
    </p>

</section>

In this example:

  • <section> is the parent.
  • <h2> is a child.
  • <p> is a child.

📐 10. Proper Indentation

Indentation makes HTML easier for developers to read and maintain.

❌ Difficult to Read 

<section><h2>About</h2><p>Hello</p></section>

✅ Easier to Read 

<section>

    <h2>
        About
    </h2>

    <p>
        Hello
    </p>

</section>

🌐 11. Complete HTML5 Example 

<!DOCTYPE html>

<html lang="en">

<head>

    <meta charset="UTF-8">

    <meta
        name="viewport"
        content="width=device-width, initial-scale=1.0"
    >

    <title>
        Golden Healing Solutions
    </title>

</head>

<body>

    <header>

        <h1>
            Golden Healing Solutions
        </h1>

    </header>


    <main>

        <section>

            <h2>
                Welcome
            </h2>

            <p>
                Welcome to our website.
            </p>

        </section>

    </main>


    <footer>

        <p>
            Copyright 2026
        </p>

    </footer>

</body>

</html>

🏛️ 12. Semantic Page Structure

A modern HTML page often uses semantic elements to organize the content. 

<body>

    <header>

        Website Header

    </header>


    <nav>

        Navigation Links

    </nav>


    <main>

        Main Page Content


        <section>

            Section Content

        </section>


        <article>

            Independent Content

        </article>

    </main>


    <footer>

        Footer Information

    </footer>

</body>
