THE BIG PICTURE

What Happens When You Visit a Website?

When you type a web address into your browser and press Enter, several technologies work together in a matter of seconds.

Your browser needs to find the correct server, communicate with that server, request the resources for the webpage, receive those resources, and then display the webpage on your screen.

CONCEPT 01

Internet vs. World Wide Web

The Internet

The Internet is the global network of interconnected computers and devices that communicate with one another.

Think of it as:

The infrastructure or network that allows computers and devices to communicate.

  • Computers
  • Servers
  • Routers
  • Network connections
  • Data transmission

The World Wide Web

The World Wide Web is a system of interconnected webpages and resources that are accessed through the Internet.

Think of it as:

One of the major services that uses the Internet to deliver information and interactive content.

  • Websites
  • Webpages
  • Web applications
  • Hyperlinks
  • Web browsers
Remember: The Internet and the Web are related, but they are not the same thing. The Internet is the underlying network. The Web is a system that operates over that network.
CONCEPT 02

Clients

What Is a Client?

A client is a device or software application that requests services or resources from another computer.

When you visit a website, your device acts as a client.

Examples of Clients

  • Desktop computers
  • Laptops
  • Smartphones
  • Tablets
  • Web browsers
Simple definition: A client asks for something.
CONCEPT 03

Servers

What Is a Server?

A server is a computer or system that provides resources, data, or services to clients.

When your browser requests a webpage, a web server can respond by sending the files needed to display that webpage.

A Server May Provide:

  • HTML files
  • CSS files
  • JavaScript files
  • Images
  • Videos
  • Data from databases
  • Web applications
Simple definition: A server responds to requests.
Client + Server: A useful way to remember the relationship is:

Client = requests
Server = responds
CONCEPT 04

Web Browsers

What Is a Browser?

A web browser is software that allows users to access and interact with websites and web applications.

Common Browsers

  • Google Chrome
  • Microsoft Edge
  • Mozilla Firefox
  • Apple Safari

What Does a Browser Do?

A browser sends requests to web servers, receives resources, interprets web technologies, and renders the resulting webpage.

For example, when the browser receives HTML, CSS, and JavaScript, it processes those resources to create the webpage you see.

CONCEPT 05

HTTP and HTTPS

HTTP

HTTP stands for Hypertext Transfer Protocol .

HTTP defines rules for communication between clients and web servers.

It is commonly used when a browser requests resources from a web server.

HTTPS

HTTPS stands for Hypertext Transfer Protocol Secure .

HTTPS uses encryption to help protect information exchanged between a browser and a website.

Look for the lock: When you visit a website using HTTPS, browsers commonly indicate the secure connection with a lock icon or similar security indicator.
Example URLs 
http://example.com

https://example.com
CONCEPT 06

URLs

What Is a URL?

URL stands for Uniform Resource Locator .

A URL is an address used to locate a resource on the Web.

Example URL 
https://www.example.com/courses/web-development

Parts of a URL

  • https:// — the protocol
  • www — a commonly used hostname prefix
  • example.com — the domain name
  • /courses/web-development — the path identifying a resource
Simple definition: A URL tells the browser where a resource can be found and how to access it.
CONCEPT 07

DNS

What Is DNS?

DNS stands for Domain Name System .

DNS helps translate human-readable domain names into IP addresses that computers use to locate systems on a network.

Why Do We Need DNS?

People can more easily remember names such as domain names than numerical IP addresses.

When you enter a domain name, DNS helps your device determine which IP address is associated with that domain.

Think of DNS like a phone book: You provide a name, and DNS helps find the corresponding network address.
CONCEPT 08

Web Hosting

What Is Web Hosting?

Web hosting is a service that provides the infrastructure needed to make a website's files and resources available over the Internet.

A website's files need to be stored somewhere so that users can access them.

Website Files May Include:

  • HTML
  • CSS
  • JavaScript
  • Images
  • Videos
  • Fonts
  • Application files
Simple definition: Web hosting provides a place for website resources to live so users can access them.

Domain vs. Hosting

A domain name is the human-readable address people use to find a website. Hosting provides the infrastructure where the website's resources are stored and served.

Easy analogy: Think of a website like a physical business.

Domain = street address
Hosting = building/location
Website files = contents of the building
PUT IT ALL TOGETHER

What Happens When You Enter a URL?

Example

Browser Address Bar 
https://www.example.com

Step 1 — You Enter the URL

You type a URL into your browser and press Enter.

Step 2 — The Browser Reads the URL

The browser identifies information such as the protocol and domain.

Step 3 — DNS Helps Find the Server

DNS helps determine the IP address associated with the domain name.

Step 4 — The Browser Sends a Request

The browser communicates with the appropriate web server using web protocols such as HTTP or HTTPS.

Step 5 — The Server Responds

The server processes the request and sends back the requested resources.

Step 6 — The Browser Receives the Resources

The browser receives resources such as HTML, CSS, JavaScript, images, and other data.

Step 7 — The Browser Renders the Page

The browser processes the resources and displays the webpage on your screen.

REAL-WORLD EXAMPLE

Let's Say You Visit a Website

Imagine you open your browser and type: 

https://www.mywebsite.com

Your computer does not simply "go" to the website like driving to a physical address. Instead, several systems communicate with one another.

  • Your device acts as a client.
  • Your browser interprets the URL.
  • DNS helps locate the server.
  • HTTPS provides the communication protocol for the secure connection.
  • The server receives the request.
  • The server sends the requested resources.
  • The browser processes the resources.
  • The webpage appears on your screen.
