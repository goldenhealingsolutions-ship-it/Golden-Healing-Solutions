2.4 — Headings & Paragraphs

Learn how to organize webpage content using HTML headings and paragraphs to create clear, readable, accessible, and well-structured web pages.

🎯 Learning Objectives

By the end of this lesson, you should be able to:

  • Explain the purpose of HTML headings.
  • Use heading elements from <h1> through <h6>.
  • Understand the importance of heading hierarchy.
  • Explain the purpose of the <p> element.
  • Create properly structured paragraphs.
  • Understand the difference between visual size and semantic importance.
  • Use headings to organize webpage content.
  • Apply heading and paragraph best practices.
  • Create accessible content structures.

📖 1. Introduction to Headings & Paragraphs

Headings and paragraphs are two of the most important HTML elements used to organize written content.

Headings identify sections of content, while paragraphs contain blocks of text.

Together, they help users understand the organization and meaning of a webpage. 

<h1>My Website</h1>

<p>
    Welcome to my website.
</p>

🏷️ 2. HTML Heading Elements

HTML provides six levels of headings:

<h1> — Highest-level heading
<h2> — Second-level heading
<h3> — Third-level heading
<h4> — Fourth-level heading
<h5> — Fifth-level heading
<h6> — Sixth-level heading

1️⃣ 3. The <h1> Element

The <h1> element represents the primary heading of a page or major content section. 

<h1>
    Web Development Bootcamp
</h1>
Best Practice:

Use the <h1> to clearly identify the main subject or purpose of the page.

2️⃣ 4. The <h2> Element

The <h2> element is commonly used for major sections underneath the main heading. 

<h1>
    Web Development Bootcamp
</h1>

<h2>
    Introduction to HTML
</h2>

<h2>
    Introduction to CSS
</h2>

🔢 5. Headings & Hierarchy

Headings can be organized into a hierarchy. For example: 

<h1>
    Web Development Bootcamp
</h1>

<h2>
    HTML
</h2>

<h3>
    HTML Elements
</h3>

<h3>
    HTML Attributes
</h3>

<h2>
    CSS
</h2>

<h3>
    CSS Selectors
</h3>

This structure makes the relationship between sections clear.

👀 6. Heading Size vs. Semantic Meaning

Important:

Heading levels should not be selected simply because one heading looks larger or smaller.

HTML headings communicate the structure and importance of content. CSS should be used to control visual appearance.

HTML 

<h2>
    Course Overview
</h2>

CSS 

h2 {
    font-size: 32px;
}

📄 7. The <p> Element

The <p> element represents a paragraph. 

<p>
    HTML is the standard markup language used
    to structure content on the web.
</p>

Paragraphs make long blocks of written content easier to organize and read.

📚 8. Multiple Paragraphs

Separate ideas should generally be placed into separate paragraph elements. 

<p>
    HTML provides the structure of a webpage.
</p>

<p>
    CSS controls the visual presentation.
</p>

<p>
    JavaScript adds behavior and interactivity.
</p>
Tip:

Do not put an entire article into one giant paragraph. Break content into logical sections.

🧱 9. Combining Headings & Paragraphs 

<h1>
    Web Development
</h1>

<p>
    Learn how websites are designed and developed.
</p>

<h2>
    HTML
</h2>

<p>
    HTML provides the structure of a webpage.
</p>

<h2>
    CSS
</h2>

<p>
    CSS controls the appearance of the webpage.
</p>

⭐ 11. Heading Best Practices

  • Use headings to describe sections of content.
  • Keep heading levels logically organized.
  • Use <h1> for the primary page heading.
  • Use <h2> for major sections.
  • Use <h3> for subsections of an <h2>.
  • Do not choose headings simply because they look visually attractive.
  • Use CSS to change heading appearance.
  • Keep heading text descriptive and meaningful.

♿ 12. Accessibility & Headings

Proper heading structure is important for accessibility.

Screen-reader users can use headings to navigate through a webpage and understand its structure. 

<h1>Online Learning Platform</h1>

<h2>Web Development</h2>

<h3>HTML</h3>

<h3>CSS</h3>

<h2>Project Management</h2>

<h3>Project Planning</h3>
Accessibility Principle:

Use headings based on content hierarchy, not merely visual size.

⚠️ 13. Common Mistakes

❌ Mistake #1 

<h1>Title</h1>

<h4>Section</h4>

Jumping heading levels without a meaningful reason can create a confusing structure.

❌ Mistake #2 

<h1>
    This is a paragraph
    with lots of text...
</h1>

Headings should not be used as replacements for paragraphs.

<h1>Web Development Bootcamp</h1>

↩️ 15. The <br> Element

The <br> element creates a line break. 

<p>
    Golden Healing Solutions<br>
    Web Development Bootcamp
</p>
Important:

Do not use repeated <br> elements simply to create spacing between paragraphs. Use separate paragraphs and CSS for layout and spacing.

↔️ 16. Whitespace in HTML

HTML generally collapses consecutive spaces and line breaks in normal text. 

<p>
    Hello
    World
</p>

The browser will generally display the text as:

Hello World

Remember:

Use CSS when you need precise control over spacing, rather than adding many spaces in your HTML.

💻 17. Hands-On Practice

Build a Course Introduction Page

Create a webpage containing:

  • One <h1> for the page title.
  • At least three <h2> sections.
  • At least one <h3> subsection.
  • At least four paragraphs.
  • A logical heading hierarchy.
  • Readable and descriptive heading text.

    </p>

    </p>

</html>

📚 18. Quick Reference

Element Purpose Typical Use
<h1> Main heading Page or primary topic
<h2> Major section Main content sections
<h3> Subsection Sections within an h2
<h4> Lower-level subsection Detailed organization
<h5> Lower-level heading Detailed content
<h6> Lowest heading level Highly specific subsections
<p> Paragraph Blocks of written content
<br> Line break Intentional line breaks
