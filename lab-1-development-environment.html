HANDS-ON LAB • LAB 1

Set Up Your Development Environment

In this hands-on lab, you will prepare your computer for web development and create your first webpage using HTML.

Difficulty Beginner
Estimated Time 30–45 Minutes
Lab Type Hands-On Practice

Lab Objectives

By the end of this lab, you should be able to:

01. Install Visual Studio Code.
02. Create a project folder for your website.
03. Create an HTML file.
04. Open your HTML file in a web browser.
05. Create and view your first webpage.

Required Tools

  • ✓ Computer with internet access
  • ✓ Visual Studio Code
  • ✓ A modern web browser
    Chrome, Microsoft Edge, Firefox, Safari, or another modern browser
1

Install Visual Studio Code

Visual Studio Code, commonly called VS Code, is a source-code editor used by developers to create and edit websites and applications.

Download and install Visual Studio Code on your computer.

  • Download VS Code from the official Microsoft Visual Studio Code website.
  • Choose the installer for your operating system.
  • Run the installer.
  • Follow the installation instructions.
  • Open Visual Studio Code after installation.
💡 Tip: You will use VS Code throughout this bootcamp to write HTML, CSS, and JavaScript.
2

Create Your Project Folder

A project folder keeps all of the files associated with your website organized in one location.

Create a new folder on your computer.

Name your folder:

Folder Name 
web-development-lab-1

You can place the folder somewhere easy to find, such as your Desktop or Documents folder.

💡 Why does this matter? Professional developers organize projects into folders so that files are easier to manage, edit, test, and share.
3

Open Your Project in VS Code

Open Visual Studio Code and open the project folder you just created.

In VS Code:

  • Select File.
  • Select Open Folder.
  • Find your web-development-lab-1 folder.
  • Select the folder.
  • Click Select Folder.
💡 Checkpoint: Your project folder should now appear in the VS Code Explorer panel.
4

Create Your HTML File

Inside your project folder, create a new file named:

File Name 
index.html

The file extension .html tells your computer that this is an HTML document.

⚠️ Important: Make sure the file is named index.html and not index.html.txt.
5

Create Your First Webpage

Copy the following HTML into your index.html file.

index.html 
<!DOCTYPE html>

<html lang="en">

<head>

    <meta charset="UTF-8">

    <meta
        name="viewport"
        content="width=device-width, initial-scale=1.0"
    >

    <title>
        My First Webpage
    </title>

</head>


<body>

    <h1>
        Welcome to My First Webpage!
    </h1>

    <p>
        My name is [Your Name].
    </p>

    <p>
        I am learning web development
        with Golden Healing Solutions.
    </p>

    <h2>
        My First Web Development Project
    </h2>

    <p>
        I created this webpage using HTML.
    </p>

</body>

</html>
💡 Personalize It: Replace [Your Name] with your actual name. You can also change the text inside the headings and paragraphs.
6

Save Your HTML File

Save your file after entering your HTML code.

You can save the file by:

  • Selecting File → Save
  • Or pressing Ctrl + S on Windows.
  • Or pressing Command + S on macOS.
💡 Developer Habit: Get into the habit of saving your work frequently.
7

Open Your Webpage in a Browser

Now it is time to see your HTML code become an actual webpage.

Locate your index.html file on your computer.

  • Open the folder containing your project.
  • Find index.html .
  • Double-click the file.
  • Your web browser should open the webpage.
🎉 Congratulations! You have just created and opened your first webpage.
8

Make a Change

Your first webpage is only the beginning. Return to VS Code and change the text inside your webpage.

For example, change: 

<h1>
    Welcome to My First Webpage!
</h1>

to something like: 

<h1>
    Welcome to My Web Development Journey!
</h1>

Save your file and refresh your browser.

Your webpage should now display your changes.

Lab Completion Checklist

Check each requirement after you complete it.

Ready to Complete the Lab?

Make sure you have completed every requirement above before marking this lab as complete.

🎉 Lab 1 Completed!
Your development environment is ready.
