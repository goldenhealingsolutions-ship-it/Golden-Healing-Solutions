18.3 — Requirements

Review the technical, functional, design, accessibility, and submission requirements your Capstone Project must meet before it can be submitted for Final Project Review.

🎯 Learning Objectives

  • Identify the required technical components of the Capstone Project.
  • Demonstrate appropriate HTML, CSS, and JavaScript implementation.
  • Create a functional and responsive website or web application.
  • Apply accessibility and usability principles.
  • Test the project before submission.
  • Verify that all required components are complete.

📌 Capstone Requirement Overview

Your Capstone Project is designed to demonstrate the knowledge and practical skills you developed throughout the Web Development Bootcamp.

The project must be functional, organized, responsive, accessible, and professionally presented.

Important:

Meeting the checklist requirements does not automatically mean your project will be approved. Your completed project will be evaluated during the Final Project Review.

💻 1. Technical Requirements

01

HTML5 Structure REQUIRED

Use properly structured HTML5 elements, including appropriate semantic elements where applicable.

02

CSS Styling REQUIRED

Use CSS to create a consistent and professional visual design.

03

JavaScript REQUIRED

Include meaningful JavaScript functionality that demonstrates user interaction or dynamic behavior.

04

File Organization REQUIRED

Organize HTML, CSS, JavaScript, images, and other project files logically.

⚙️ 2. Functional Requirements

01

Navigation

Navigation must allow users to move between appropriate pages or sections without broken links.

02

Interactive Elements

Buttons, menus, forms, tabs, or other interactive elements must perform their intended functions.

03

User Input

Where applicable, forms and user-input controls must collect information appropriately.

04

Error Handling

The project should provide appropriate feedback when users enter invalid or incomplete information.

🎨 3. Design Requirements

01

Consistent Design

Colors, typography, spacing, buttons, and layouts should create a consistent visual experience.

02

Readability

Text should be easy to read with appropriate font sizes, spacing, and contrast.

03

Visual Hierarchy

Headings, sections, buttons, and important information should be visually organized.

04

Professional Presentation

The finished project should look intentional, organized, and appropriate for its target audience.

📱 4. Responsive Design Requirements

Your project must provide an appropriate user experience across different screen sizes.

Minimum Responsive Expectations

  • Desktop layouts should display correctly.
  • Tablet layouts should remain usable.
  • Mobile layouts should remain readable and functional.
  • Content should not unnecessarily overflow the screen.
  • Images should scale appropriately.
  • Navigation should remain usable on smaller screens.
  • Buttons and form controls should remain accessible.

♿ 5. Accessibility Requirements

01

Alternative Text

Images should have meaningful alternative text when appropriate.

02

Form Labels

Form controls should have clear and descriptive labels.

03

Keyboard Access

Interactive elements should be usable with keyboard navigation where appropriate.

04

Color & Contrast

Text and important interface elements should have sufficient visual contrast.

📝 6. Content Requirements

01

Original Content

Project content should be appropriate for the project and substantially your own work.

02

Clear Information

Content should clearly communicate the purpose of the website or application.

03

Professional Writing

Review spelling, grammar, punctuation, and professional presentation.

04

External Resources

External images, libraries, fonts, code, or other resources should be used appropriately and credited when required.

🧪 7. Testing Requirements

Before Submission, Test:

  • All navigation links.
  • All buttons and interactive components.
  • Forms and input validation.
  • Images and media.
  • Responsive layouts.
  • JavaScript functionality.
  • Browser console for obvious errors.
  • Page loading and general usability.

📚 8. Documentation Requirements

Your project should include documentation that explains the purpose and construction of the project.

Project Description

Explain what your project is and what problem or purpose it addresses.

Technologies Used

Identify the primary technologies, tools, libraries, or frameworks used.

Features

Describe the major functionality included in your project.

Testing

Describe the testing and debugging performed before submission.

⚠️ 9. Project Quality Standards

Your project should NOT contain:

  • Broken navigation links.
  • Obvious JavaScript errors that prevent functionality.
  • Placeholder text that should have been replaced.
  • Missing images or broken media.
  • Unfinished sections presented as completed work.
  • Unnecessary duplicate pages or content.
  • Poorly organized project files.
  • Copied work presented as entirely your own.

✅ 10. Requirements Verification

Check each requirement after you have verified it in your project.

🎉 Requirements Verified

You have reviewed and confirmed the Capstone Project requirements.

Your next step is to continue preparing your project for Final Project Review.
