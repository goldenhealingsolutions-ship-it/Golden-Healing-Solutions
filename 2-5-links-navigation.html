2.5 — Links & Navigation

Learn how hyperlinks work in HTML and how to connect web pages, external websites, files, email addresses, page sections, and navigation menus.

🎯 Learning Objectives

By the end of this lesson, you should be able to:

  • Explain what a hyperlink is.
  • Use the HTML <a> anchor element.
  • Use the href attribute.
  • Create links to other pages.
  • Create links to external websites.
  • Create links to specific sections of a webpage.
  • Create email links.
  • Understand relative and absolute URLs.
  • Build a basic navigation menu.
  • Use descriptive link text for accessibility.

📖 1. What Are Links?

A hyperlink, commonly called a link, allows users to move from one location to another.

Links are one of the fundamental features of the web because they connect webpages and resources together. 

<a href="about.html">
    About Us
</a>

⚓ 2. The <a> Anchor Element

The HTML <a> element creates a hyperlink. 

<a href="https://example.com">
    Visit Example
</a>

The text between the opening and closing <a> tags is the clickable link text.

Visit Example Website

🔗 3. The href Attribute

The href attribute specifies the destination of a hyperlink. 

<a href="https://www.example.com">
    Example Website
</a>
Remember:

The href tells the browser where the user should go when the link is clicked.

🌎 4. External Links

An external link points to another website or domain. 

<a href="https://www.google.com">
    Google
</a>

External URLs commonly include: 

https://
Important:

When linking to an external website, make sure the URL is correct and uses HTTPS when available.

🪟 5. Opening a Link in a New Tab

The target="_blank" attribute tells the browser to open the link in a new browsing context, commonly a new tab. 

<a
    href="https://example.com"
    target="_blank"
    rel="noopener noreferrer">

    Visit Example

</a>
Security Best Practice:

When using target="_blank" for external links, using rel="noopener noreferrer" is a good practice.

📁 6. Internal Links

Internal links connect pages within the same website. 

<a href="about.html">
    About Us
</a>

<a href="contact.html">
    Contact
</a>

<a href="courses.html">
    Courses
</a>

For example, your bootcamp could contain: 

index.html
about.html
courses.html
contact.html
login.html
dashboard.html

📂 7. Relative URLs

A relative URL points to a resource based on the current location of the webpage. 

<a href="about.html">
    About
</a>

If the file is located inside another folder: 

<a href="lessons/html/about.html">
    About HTML
</a>

⬆️ 8. Moving to a Parent Folder

The ../ notation moves up one directory. 

<a href="../index.html">
    Home
</a>

For example: 

website/
│
├── index.html
│
└── lessons/
    │
    └── html/
        │
        └── lesson.html

From lesson.html, using: 

../

would move from the html folder to the lessons folder.

🌐 9. Absolute URLs

An absolute URL contains the complete web address. 

<a href="https://www.example.com/about.html">
    About
</a>

Relative URL 

about.html

Usually used for pages within your own website.

Absolute URL 

https://example.com/about.html

Contains the complete destination address.

📧 10. Email Links

The mailto: protocol can create a link that opens the user's email application. 

<a href="mailto:info@goldenhealingsolutions.com">

    Email the Instructor

</a>
Email Golden Healing Solutions

📱 11. Telephone Links

The tel: protocol can create a link that allows supported devices to initiate a phone call. 

<a href="tel:+15551234567">
    Call Us
</a>
Important:

Replace the example phone number with the actual number you intend to publish.

📍 12. Links to Sections on the Same Page

You can create links that jump directly to a specific section of the current page.

First, give the destination element an id. 

<h2 id="contact">
    Contact Us
</h2>

Then link to that ID using a hashtag: 

<a href="#contact">
    Jump to Contact
</a>

🧭 14. Navigation Menus

A navigation menu provides users with links to important areas of a website. 

<nav>

    <a href="index.html">
        Home
    </a>

    <a href="courses.html">
        Courses
    </a>

    <a href="about.html">
        About
    </a>

    <a href="contact.html">
        Contact
    </a>

</nav>

💻 15. Navigation Menu Example

Home Courses About Contact

🏗️ 16. The <nav> Element

The <nav> element identifies a section containing important navigation links. 

<nav>

    <a href="index.html">
        Home
    </a>

    <a href="courses.html">
        Courses
    </a>

    <a href="contact.html">
        Contact
    </a>

</nav>
Accessibility Benefit:

Semantic navigation elements help browsers, assistive technologies, and users understand the purpose of the content.

♿ 17. Accessible Link Text

Link text should clearly communicate where the link goes.

❌ Less Descriptive 

<a href="courses.html">
    Click Here
</a>

✅ More Descriptive 

<a href="courses.html">
    View Web Development Courses
</a>

📥 18. Download Links

The download attribute can be used when you want a link to request that a resource be downloaded. 

<a
    href="student-guide.pdf"
    download>

    Download Student Guide

</a>

🖼️ 19. Making an Image a Link

An image can be placed inside an anchor element. 

<a href="index.html">

    <img
        src="logo.png"
        alt="Golden Healing Solutions logo">

</a>
Accessibility Tip:

Always provide meaningful alt text when the image communicates information.

📚 22. Quick Reference

Code Purpose
<a> Creates a hyperlink
href Specifies the destination
target="_blank" Opens link in a new browsing context
rel="noopener noreferrer" Security/privacy-related relationship values for external new-tab links
mailto: Creates an email link
tel: Creates a telephone link
#id Links to an element ID on the page
../ Moves up one directory
download Requests downloading a linked resource
<nav> Identifies a navigation section

⭐ 23. Link Best Practices

  • Use descriptive link text.
  • Make sure links actually lead to their intended destination.
  • Use HTTPS for secure external websites whenever available.
  • Use relative URLs for appropriate internal pages.
  • Use absolute URLs when linking to external websites.
  • Use semantic <nav> elements for navigation areas.
  • Do not rely solely on color to identify links.
  • Make links easy to identify and click.
  • Use meaningful alt text when an image functions as a link.
