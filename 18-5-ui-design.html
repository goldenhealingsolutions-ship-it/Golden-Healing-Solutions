18.5 — UI Design

Transform your Capstone wireframe into a professional user interface by establishing your visual design system and interface components.

🎯 Learning Objectives

  • Define the visual identity of your Capstone project.
  • Select an appropriate color palette.
  • Establish typography and text hierarchy.
  • Design consistent buttons, cards, forms, navigation, and other interface components.
  • Apply spacing and visual hierarchy principles.
  • Design for accessibility and responsive layouts.
  • Create a consistent user interface across pages.

📖 What Is UI Design?

User Interface (UI) Design is the process of designing the visual elements users interact with on a website or application.

This includes colors, typography, buttons, forms, navigation, cards, icons, spacing, images, and other visual elements.

Your wireframe established where elements belong. Your UI design establishes what those elements look like and how they interact.

🧠 Core UI Design Principles

🎯

Consistency

Use consistent colors, typography, spacing, buttons, and components throughout the website.

👁️

Visual Hierarchy

Use size, spacing, contrast, and positioning to guide the user's attention.

📐

Alignment

Align elements intentionally to create an organized and professional interface.

⚖️

Balance

Distribute content and visual elements so the interface does not feel overcrowded.

🔍

Clarity

Users should understand what information is being presented and what actions they can take.

♿

Accessibility

Design interfaces that can be understood and used by as many people as possible.

8. ♿ Accessibility

Accessibility Checklist

  • Use readable text sizes.
  • Maintain appropriate color contrast.
  • Provide visible focus states.
  • Use meaningful labels for forms.
  • Use alternative text for appropriate images.
  • Do not rely on color alone to communicate information.
  • Make interactive controls easy to identify.
