2.8 — Tables

Learn how to organize structured data using HTML tables, including rows, columns, headers, captions, spanning cells, and accessible table structure.

🎯 Learning Objectives

By the end of this lesson, you should be able to:

  • Understand the purpose of HTML tables.
  • Create a basic HTML table.
  • Use table rows and cells.
  • Create table headers.
  • Use table captions.
  • Understand thead, tbody, and tfoot.
  • Use colspan and rowspan.
  • Style tables with CSS.
  • Create responsive tables.
  • Use tables appropriately for structured data.

📖 1. What Are HTML Tables?

An HTML table is used to organize information into rows and columns.

Tables are useful when information has a relationship between different pieces of data.

Examples include course schedules, employee information, product specifications, grades, financial data, and reports.

Important:

HTML tables should generally be used for tabular data, not simply to position or lay out webpage elements.

🏗️ 2. Creating a Basic Table

The <table> element creates the table. A row is created using <tr>, and a normal data cell is created using <td>.

Example 
<table>

    <tr>

        <td>HTML</td>

        <td>Beginner</td>

    </tr>


    <tr>

        <td>CSS</td>

        <td>Intermediate</td>

    </tr>

</table>
HTML Beginner
CSS Intermediate

↔️ 3. Table Rows

The <tr> element means table row. 

<tr>

    <td>HTML</td>

    <td>Web Development</td>

</tr>
Remember:

Every row of a table is created with <tr>.

📦 4. Table Data Cells

The <td> element represents a standard data cell. 

<td>HTML</td>

<td>CSS</td>

<td>JavaScript</td>

🔤 5. Table Header Cells

The <th> element creates a table header cell. 

<tr>

    <th>Course</th>

    <th>Level</th>

    <th>Duration</th>

</tr>

Best Practice:

Use <th> for cells that identify the meaning of a row or column.

🏷️ 6. Table Captions

The <caption> element provides a title or description for a table. 

<table>

    <caption>
        Student Grades
    </caption>


    <tr>

        <th>Student</th>

        <th>Score</th>

    </tr>


    <tr>

        <td>Jordan</td>

        <td>92%</td>

    </tr>

</table>

🔝 7. Table Head, Body & Footer

Larger tables can be divided into three logical sections:

  • <thead> — Header content
  • <tbody> — Main table data
  • <tfoot> — Footer or summary content 
<table>


    <thead>

        <tr>

            <th>Course</th>

            <th>Students</th>

        </tr>

    </thead>


    <tbody>

        <tr>

            <td>HTML</td>

            <td>25</td>

        </tr>

    </tbody>


    <tfoot>

        <tr>

            <td>Total</td>

            <td>25</td>

        </tr>

    </tfoot>


</table>

↔️ 8. colspan

The colspan attribute allows one cell to span across multiple columns. 

<table>

    <tr>

        <th colspan="2">
            Web Development
        </th>

    </tr>


    <tr>

        <td>HTML</td>

        <td>CSS</td>

    </tr>

</table>
Web Development
HTML CSS

↕️ 9. rowspan

The rowspan attribute allows a cell to span across multiple rows. 

<table>

    <tr>

        <th rowspan="2">
            HTML
        </th>

        <td>Elements</td>

    </tr>


    <tr>

        <td>Attributes</td>

    </tr>

</table>
HTML Elements
Attributes

♿ 10. Table Accessibility

Tables should be structured so that assistive technologies can understand the relationship between headers and data.

The scope attribute can identify whether a header applies to a column or row. 

<table>

    <tr>

        <th scope="col">
            Student
        </th>

        <th scope="col">
            Grade
        </th>

    </tr>


    <tr>

        <th scope="row">
            Jordan
        </th>

        <td>
            95%
        </td>

    </tr>

</table>
Accessibility Tip:

Meaningful table headers help users understand what each piece of data represents.

🎨 11. Styling Tables with CSS

CSS can control the appearance of HTML tables. 

table {
    width: 100%;
    border-collapse: collapse;
}

th {
    background: #111;
    color: white;
    padding: 12px;
}

td {
    padding: 12px;
    border: 1px solid #ddd;
}

📏 12. border-collapse

The border-collapse property determines how table borders interact. 

table {
    border-collapse: collapse;
}

Separate Borders 

border-collapse:
separate;

Collapsed Borders 

border-collapse:
collapse;

📱 13. Responsive Tables

Large tables can become difficult to view on mobile devices. A common approach is to place the table inside a horizontally scrollable container. 

.table-wrapper {
    overflow-x: auto;
}

table {
    min-width: 600px;
}
Why?

Instead of forcing a large table to shrink too much, the user can horizontally scroll to see all columns.

⚖️ 14. Tables vs. Lists

📊 Use a Table When:

  • Data belongs in rows and columns.
  • Multiple values need to be compared.
  • Information has relationships between columns.
  • You are displaying structured data.

📋 Use a List When:

  • Items are simply grouped together.
  • You are showing steps.
  • You are creating navigation.
  • Information does not require rows and columns.

📚 18. Quick Reference

Element / Attribute Purpose
<table> Creates a table
<tr> Creates a table row
<td> Creates a standard data cell
<th> Creates a header cell
<caption> Provides a table title or description
<thead> Groups table header content
<tbody> Groups the main table content
<tfoot> Groups table footer content
colspan Allows a cell to span multiple columns
rowspan Allows a cell to span multiple rows
scope Identifies the relationship of a header to data

⚠️ 19. Common Table Mistakes

❌ Avoid

  • Using tables for webpage layout.
  • Leaving out meaningful headers.
  • Creating unnecessarily complicated tables.
  • Using tables when a list would be more appropriate.
  • Ignoring mobile responsiveness.

✅ Use

  • Tables for structured data.
  • Meaningful table headers.
  • Captions when helpful.
  • Semantic table sections.
  • Responsive table containers.
