2.6 — Images & Multimedia

Learn how to add images, audio, video, captions, responsive media, and accessible multimedia content to HTML webpages.

🎯 Learning Objectives

By the end of this lesson, you should be able to:

  • Use the HTML <img> element.
  • Understand the src and alt attributes.
  • Use appropriate image file formats.
  • Control image dimensions with HTML and CSS.
  • Create responsive images.
  • Understand <figure> and <figcaption>.
  • Add audio to a webpage.
  • Add video to a webpage.
  • Use media controls.
  • Understand multimedia accessibility.

📖 1. What Is Multimedia?

Multimedia refers to content that combines different types of media such as text, images, audio, video, animations, and interactive elements.

Modern websites use multimedia to communicate information, demonstrate concepts, tell stories, and improve user engagement.

🖼️ Images

Photographs, graphics, logos, icons, illustrations, and diagrams.

🎵 Audio

Music, narration, podcasts, sound effects, and recordings.

🎥 Video

Tutorials, demonstrations, presentations, and promotional content.

🎞️ Animation

Motion graphics and animated visual content.

🖼️ 2. Adding Images with <img>

The HTML <img> element displays an image on a webpage. 

<img
    src="images/logo.png"
    alt="Golden Healing Solutions logo">

The <img> element is a void element, meaning it does not require a closing </img> tag.

📁 3. The src Attribute

The src attribute specifies the location of the image file. 

<img
    src="images/student.jpg"
    alt="Student working on a laptop">

The image can be located in the same directory: 

src="photo.jpg"

Or inside a folder: 

src="images/photo.jpg"

♿ 4. The alt Attribute

The alt attribute provides alternative text for an image. 

<img
    src="student.jpg"
    alt="Student completing a web development project">
Why is alt text important?
  • It helps users who use screen readers.
  • It provides information if an image cannot load.
  • It improves accessibility.
  • It communicates the purpose of meaningful images.

🎨 5. Decorative Images

If an image is purely decorative and provides no meaningful information, its alternative text can be empty. 

<img
    src="decorative-line.png"
    alt="">
Important:

Do not leave alt out simply because an image does not appear important. Determine whether the image is meaningful or decorative first.

📐 6. Image Dimensions

Images can have width and height attributes. 

<img
    src="photo.jpg"
    alt="Mountain landscape"
    width="600"
    height="400">

CSS is often preferred when controlling presentation and responsive sizing. 

img {
    max-width: 100%;
    height: auto;
}

📱 7. Responsive Images

A responsive image adjusts to fit the available screen size. 

img {
    max-width: 100%;
    height: auto;
}
Key Concept:

max-width: 100% prevents an image from becoming wider than its containing element.

📝 10. Figure & Figcaption

The <figure> element can group an image with related content such as a caption. 

<figure>

    <img
        src="workspace.jpg"
        alt="Developer working at a computer">

    <figcaption>
        A web developer working on a website.
    </figcaption>

</figure>

🎵 11. Adding Audio

The <audio> element embeds sound content. 

<audio controls>

    <source
        src="lesson-audio.mp3"
        type="audio/mpeg">

    Your browser does not support audio.

</audio>
controls

The controls attribute provides browser controls such as play, pause, volume, and progress.

🎧 12. Audio File Types

Format MIME Type
MP3 audio/mpeg
WAV audio/wav
Ogg audio/ogg

🎥 13. Adding Video

The <video> element embeds video content. 

<video controls width="640">

    <source
        src="lesson-video.mp4"
        type="video/mp4">

    Your browser does not support video.

</video>

▶️ 14. Video Controls

Common video attributes include:

Attribute Purpose
controls Displays playback controls
autoplay Requests automatic playback
muted Starts media muted
loop Repeats the media
poster Specifies an image shown before video playback
preload Provides a hint about how the browser should load media
Accessibility Tip:

Avoid automatically playing media with sound. Users should generally have control over when audio or video begins.

🎬 15. Video Poster Images

A poster image provides a preview image before video playback. 

<video
    controls
    poster="video-preview.jpg">

    <source
        src="lesson.mp4"
        type="video/mp4">

</video>

♿ 16. Video Captions

The <track> element can provide timed text such as captions. 

<video controls>

    <source
        src="lesson.mp4"
        type="video/mp4">

    <track
        src="captions.vtt"
        kind="captions"
        srclang="en"
        label="English"
        default>

</video>
Why captions matter:
  • They help deaf and hard-of-hearing users.
  • They allow users to follow video when audio is unavailable.
  • They can help users understand technical terminology.

🔄 17. Multiple Media Sources

You can provide multiple source formats so the browser can select a supported format. 

<video controls>

    <source
        src="lesson.mp4"
        type="video/mp4">

    <source
        src="lesson.webm"
        type="video/webm">

    Your browser does not support video.

</video>

🌐 18. Embedded Multimedia

Webpages can also embed content from other services using elements such as <iframe>, when the external service permits embedding. 

<iframe
    src="https://example.com"
    title="Example embedded content"
    width="800"
    height="450">

</iframe>
Security & Privacy:

Only embed content from sources you trust, and follow the service's embedding policies.

♿ 19. Multimedia Accessibility

  • Provide meaningful alt text for informative images.
  • Use empty alt="" for appropriate decorative images.
  • Provide captions for video when needed.
  • Provide transcripts for important audio content.
  • Avoid flashing content that could create accessibility problems.
  • Allow users to control audio and video playback.
  • Use descriptive titles for embedded content.

⚡ 20. Multimedia Performance

Large images and videos can significantly increase page loading time.

❌ Poor Practice

  • Huge image files
  • Uncompressed photographs
  • Unnecessary videos
  • No responsive sizing
  • Loading every image immediately

✅ Better Practice

  • Compress images appropriately
  • Use suitable file formats
  • Resize images appropriately
  • Use responsive techniques
  • Use lazy loading when appropriate

🚀 21. Lazy Loading Images

The loading="lazy" attribute can tell the browser that an image may be loaded when it approaches the user's viewport. 

<img
    src="large-image.jpg"
    alt="Web development classroom"
    loading="lazy">
Remember:

Lazy loading can help reduce unnecessary initial resource loading, especially on pages containing many images.

🔗 22. Making an Image a Link

Images can be placed inside links. 

<a href="courses.html">

    <img
        src="course-image.jpg"
        alt="View web development courses">

</a>

⭐ 25. Multimedia Best Practices

  • Use descriptive alternative text for meaningful images.
  • Use appropriate image formats.
  • Compress large media files.
  • Make images responsive.
  • Provide captions for video when appropriate.
  • Provide transcripts for important audio.
  • Allow users to control media.
  • Avoid unnecessary autoplay with sound.
  • Use loading="lazy" where appropriate.
  • Use descriptive captions and titles.
