18.1 — Capstone Requirements

Your Capstone Project is the final practical demonstration of the web development skills you developed throughout this bootcamp.

🎯 Learning Objectives

By the end of this lesson, you should understand what is required to successfully complete your Capstone Project.

  • Identify all required components of the Capstone Project.
  • Apply HTML, CSS, and JavaScript skills to a complete website.
  • Create a responsive and accessible user experience.
  • Test and troubleshoot your project before submission.
  • Prepare your project for Final Project Review.

📋 What Is the Capstone Project?

The Capstone Project is your opportunity to demonstrate that you can take the concepts learned throughout the Web Development Bootcamp and apply them to a complete website or web application.

Your project should demonstrate planning, structure, design, functionality, responsiveness, accessibility, and testing.

The project should be substantially your own work. Any external assets, libraries, images, fonts, or code must be used appropriately and credited when required.

💻 Required Capstone Components

01

HTML Structure

Your project must contain properly structured HTML5 elements and a logical page hierarchy.

02

CSS Styling

Your project must use CSS to create a professional, consistent, and visually appealing design.

03

JavaScript Functionality

Your project must demonstrate appropriate JavaScript functionality and user interaction.

04

Responsive Design

Your website must adapt appropriately to desktop, tablet, and mobile screen sizes.

05

Navigation

Users should be able to move between the appropriate pages and sections of your website.

06

User Interaction

Interactive elements should function correctly, including buttons, forms, menus, and other interactive features.

07

Accessibility

Use semantic HTML, descriptive labels, alternative text, keyboard-friendly controls, and other appropriate accessibility practices.

08

Testing & Debugging

Test your project for broken links, layout problems, JavaScript errors, and other issues before submitting it.

09

Professional Presentation

Your final website should have a consistent visual identity, readable content, organized layouts, and professional presentation.

10

Project Documentation

Provide a clear description of your project, technologies used, purpose, and major features.

🛠️ Recommended Technologies

Your Capstone should demonstrate the technologies covered throughout the bootcamp.

Core Technologies

HTML5 CSS3 JavaScript Responsive Design DOM Forms Git / GitHub

📐 Minimum Project Requirements

  • At least one complete, functional website or web application.
  • At least three connected pages or equivalent application views where appropriate.
  • A consistent navigation system.
  • Responsive layouts for different screen sizes.
  • CSS styling beyond browser-default styles.
  • JavaScript functionality that provides meaningful user interaction.
  • At least one functional form or user-input component when appropriate to the project.
  • Images and other media should be optimized and used appropriately.
  • Accessibility considerations must be incorporated.
  • The project must be tested before submission.
