QUESTION 1 OF 20

Which declaration tells the browser that an HTML document uses the HTML5 standard?

Correct Answer: A

<!DOCTYPE html> tells the browser that the document uses the modern HTML standard.

QUESTION 2 OF 20

Which element contains the visible content of an HTML webpage?

Correct Answer: B

The <body> element contains the primary visible content of the webpage.

QUESTION 3 OF 20

What is an HTML attribute?

Correct Answer: A

Attributes provide additional information or configuration for HTML elements.

QUESTION 4 OF 20

Which element represents the highest-level heading?

Correct Answer: A

The heading hierarchy runs from h1 through h6, with h1 representing the highest level.

QUESTION 5 OF 20

Which element creates a hyperlink?

Correct Answer: B

The anchor <a> element creates hyperlinks. The href attribute specifies the destination.

QUESTION 6 OF 20

Which attribute specifies the destination of a hyperlink?

Correct Answer: B

The href attribute specifies the URL or destination of an anchor link.

QUESTION 7 OF 20

Which attribute provides alternative text for an image?

Correct Answer: B

The alt attribute provides alternative text for an image and is important for accessibility.

QUESTION 8 OF 20

Which element creates an unordered list?

Correct Answer: B

The <ul> element creates an unordered list.

QUESTION 9 OF 20

Which element represents an individual list item?

Correct Answer: B

The <li> element represents an individual list item.

QUESTION 10 OF 20

Which element represents a table row?

Correct Answer: B

The <tr> element represents a table row.

QUESTION 11 OF 20

Which input type is designed for entering an email address?

Correct Answer: B

The email input type provides semantics and browser validation appropriate for email addresses.

QUESTION 12 OF 20

Which form attribute identifies where submitted data is sent?

Correct Answer: A

The action attribute identifies the destination URL for submitted form data.

QUESTION 13 OF 20

Which semantic element identifies a navigation section?

Correct Answer: B

The <nav> element identifies a section containing navigation links.

QUESTION 14 OF 20

What is a major benefit of semantic HTML?

Correct Answer: A

Semantic HTML communicates the meaning and structure of content to browsers, developers, and assistive technologies.

QUESTION 15 OF 20

Which attribute associates a label with a form control?

Correct Answer: A

The label's for attribute should match the id of the associated form control.

QUESTION 16 OF 20

Which feature provides alternative text for users who cannot perceive an image?

Correct Answer: A

Alternative text helps communicate the purpose or content of an image when the image cannot be perceived.

QUESTION 17 OF 20

Which Web Storage object generally persists data after the browser is closed?

Correct Answer: B

localStorage generally persists data between browser sessions until the stored data is removed.

QUESTION 18 OF 20

Which API provides a drawing surface controlled by JavaScript?

Correct Answer: A

The Canvas API allows JavaScript to draw graphics on a canvas element.

QUESTION 19 OF 20

Which API can request a user's geographic location?

Correct Answer: A

The Geolocation API allows a website to request geographic location, subject to browser permissions and availability.

QUESTION 20 OF 20

Which API is commonly used by JavaScript to make network requests?

Correct Answer: A

The Fetch API provides a modern way for JavaScript to make network requests and process responses.
