Concept 01

What Is a Development Environment?

A development environment is the collection of software, tools, settings, and resources a developer uses to create, test, debug, and manage software.

As a web developer, you will need more than just a web browser. You need a place to write your code, tools to test your work, and systems for managing different versions of your files.

THE BIG IDEA Your development environment is your digital workspace. It is similar to a physical workspace where a professional keeps the equipment and resources needed to perform their job.

The Four Tools You Will Install

Your online collaboration and repository platform. GitHub allows you to store repositories online and collaborate with others.

Tool 01

Visual Studio Code

Visual Studio Code, commonly called VS Code, is a source-code editor used by developers to create and manage software projects.

Why Are We Using VS Code?

A developer needs an application where they can create and edit code files.

VS Code provides features that make software development easier, including:

  • Syntax highlighting
  • Code completion
  • File and folder management
  • Extensions
  • Integrated terminal
  • Debugging tools
  • Source-control integration
  • Customizable settings
STUDENT TIP VS Code is a code editor. It is not the same thing as the web browser you use to view your webpage.

Understanding the VS Code Interface

When you open VS Code, you will see several important areas.

  • Explorer: Shows your files and folders.
  • Editor: The area where you write code.
  • Activity Bar: Provides access to Explorer, Search, Source Control, Run, Extensions, and other features.
  • Terminal: Allows you to execute command-line instructions.
  • Status Bar: Displays information about the current file and editor state.
Tool 02

Web Browser

A web browser is software that allows users to access and interact with resources available on the web.

Examples include browsers such as Chrome, Microsoft Edge, Firefox, and Safari.

Developers Use Browsers for More Than Browsing

Web developers use browsers to:

  • Open and test webpages
  • Test responsive layouts
  • Inspect HTML elements
  • Inspect CSS styles
  • View JavaScript errors
  • Test network requests
  • Analyze page performance
  • Test accessibility-related features

Developer Tools

Modern browsers contain a collection of tools commonly called Developer Tools or DevTools.

DevTools allows developers to inspect and troubleshoot webpages.

IMPORTANT Your browser is not just where your customers view a website. It is also one of your most important development and testing tools.
Tool 03

Git

Git is a distributed version-control system.

Version control allows developers to track changes made to files over time.

Imagine that you create a webpage today. Tomorrow, you make changes. The next day, you make additional changes and accidentally break something.

Without version control, recovering an older version can be difficult.

Git helps solve this problem by keeping a history of changes.

SIMPLE DEFINITION Git helps you track and manage changes to your code.

Installing Git

1

Download Git

Download Git from the official Git website.

2

Install Git

Run the installer and follow the installation instructions.

3

Open Your Terminal

VS Code includes an integrated terminal that you can use to interact with Git.

4

Verify Git

Enter the following command:

Terminal
$ git --version
SUCCESS If Git is installed correctly, the terminal should return a Git version number.

Basic Git Vocabulary

  • Repository: A location where a project and its version history are stored.
  • Commit: A recorded set of changes.
  • Branch: A separate line of development.
  • Clone: Creating a local copy of a repository.
  • Push: Sending local commits to a remote repository.
  • Pull: Retrieving changes from a remote repository.
Tool 04

GitHub

GitHub is a platform that provides online tools for hosting Git repositories and collaborating on software projects.

Git and GitHub are related, but they are not the same thing.

Git GitHub
Version-control system Online development platform
Runs locally on your computer Hosts repositories online
Tracks file changes Supports collaboration
Can work without GitHub Commonly works with Git repositories
MEMORY TRICK Git = Version control

GitHub = Online platform for Git-based collaboration and repository hosting
