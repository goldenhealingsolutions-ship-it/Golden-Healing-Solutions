2.7 — Lists

Learn how to organize information using unordered lists, ordered lists, description lists, nested lists, and list items in HTML.

🎯 Learning Objectives

By the end of this lesson, you should be able to:

  • Understand the purpose of HTML lists.
  • Create unordered lists using <ul>.
  • Create ordered lists using <ol>.
  • Create list items using <li>.
  • Create description lists using <dl>.
  • Use <dt> and <dd>.
  • Create nested lists.
  • Understand ordered-list attributes.
  • Use CSS to style lists.
  • Choose the correct list type for different situations.

📖 1. What Are HTML Lists?

An HTML list is a collection of related items grouped together in a structured format.

Lists are commonly used for navigation menus, instructions, features, requirements, steps, shopping lists, course objectives, and many other types of information.

Important:

HTML lists provide structure and meaning. CSS can then be used to control how the list looks.

🔵 2. Unordered Lists

An unordered list is used when the order of the items does not matter.

The <ul> element creates an unordered list, while each item is placed inside an <li> element.

Example 
<ul>

    <li>HTML</li>

    <li>CSS</li>

    <li>JavaScript</li>

</ul>

Result

  • HTML
  • CSS
  • JavaScript

🔢 3. Ordered Lists

An ordered list is used when the order of the items matters.

The <ol> element creates an ordered list.

Example 
<ol>

    <li>Create your HTML file.</li>

    <li>Add your CSS.</li>

    <li>Test your webpage.</li>

</ol>

Result

  1. Create your HTML file.
  2. Add your CSS.
  3. Test your webpage.

📌 4. The <li> Element

The <li> element represents an individual list item. 

<ul>

    <li>First item</li>

    <li>Second item</li>

    <li>Third item</li>

</ul>
Remember:

A list item should normally be contained within a list such as <ul>, <ol>, or <menu>.

⚖️ 5. Unordered vs. Ordered Lists

🔵 Unordered List

Use when sequence does not matter.

  • HTML
  • CSS
  • JavaScript
<ul>

🔢 Ordered List

Use when sequence or ranking matters.

  1. Register
  2. Complete training
  3. Take exam
<ol>

🔠 6. Ordered List Types

Ordered lists can display different numbering systems. 

<ol type="A">

    <li>HTML</li>

    <li>CSS</li>

    <li>JavaScript</li>

</ol>

The type attribute can specify different numbering styles.

Type Example
1 1, 2, 3
A A, B, C
a a, b, c
I I, II, III
i i, ii, iii
Best Practice:

For most visual styling, CSS is preferred over the HTML type attribute.

▶️ 7. Changing the Starting Number

The start attribute can change the starting number of an ordered list. 

<ol start="5">

    <li>HTML</li>

    <li>CSS</li>

    <li>JavaScript</li>

</ol>

This produces:

  1. HTML
  2. CSS
  3. JavaScript

🔄 8. Reversed Lists

The reversed attribute causes an ordered list to count downward. 

<ol reversed>

    <li>Final Step</li>

    <li>Second Step</li>

    <li>First Step</li>

</ol>

🌳 9. Nested Lists

A nested list is a list placed inside another list item. 

<ul>

    <li>
        Front-End Development

        <ul>

            <li>HTML</li>

            <li>CSS</li>

            <li>JavaScript</li>

        </ul>

    </li>


    <li>
        Back-End Development

        <ul>

            <li>Server</li>

            <li>Database</li>

            <li>API</li>

        </ul>

    </li>

</ul>

Web Development

  • Front-End Development
    • HTML
    • CSS
    • JavaScript
  • Back-End Development
    • Server
    • Database
    • API

📚 10. Description Lists

A description list is used to group terms with their corresponding descriptions.

A description list uses:

  • <dl> — Description list
  • <dt> — Description term
  • <dd> — Description/details 
<dl>

    <dt>HTML</dt>

    <dd>
        HyperText Markup Language
    </dd>


    <dt>CSS</dt>

    <dd>
        Cascading Style Sheets
    </dd>


    <dt>JavaScript</dt>

    <dd>
        A programming language used to
        create interactive webpages.
    </dd>

</dl>

Result

HTML
HyperText Markup Language
CSS
Cascading Style Sheets
JavaScript
A programming language used to create interactive webpages.

🧭 11. Lists & Navigation Menus

Lists are commonly used to structure website navigation. 

<nav>

    <ul>

        <li>
            <a href="index.html">
                Home
            </a>
        </li>

        <li>
            <a href="courses.html">
                Courses
            </a>
        </li>

        <li>
            <a href="contact.html">
                Contact
            </a>
        </li>

    </ul>

</nav>
Why use a list?

A navigation menu is conceptually a group of related links, so a list provides useful structural meaning.

🎨 12. Styling Lists with CSS

CSS can change the appearance of list markers. 

ul {
    list-style-type: square;
}

Common unordered list marker values include:

  • disc
  • circle
  • square

🚫 13. Removing List Markers

A common technique for navigation menus is removing the default list markers. 

ul {
    list-style-type: none;
    padding: 0;
    margin: 0;
}

↔️ 14. Horizontal Navigation

CSS can also turn list items into horizontal navigation links. 

nav ul {
    list-style: none;
    padding: 0;
    display: flex;
    gap: 20px;
}

nav li {
    display: inline;
}
HTML provides the structure.

CSS controls the presentation and layout.

🏗️ 15. Multi-Level Lists

Lists can contain multiple levels of information. 

<ol>

        Learn HTML

        <ol>

            <li>Elements</li>

            <li>Attributes</li>

            <li>Forms</li>

        </ol>

    </li>


    <li>
        Learn CSS

        <ol>

            <li>Selectors</li>

            <li>Properties</li>

            <li>Responsive Design</li>

        </ol>

    </li>

</ol>

⚠️ 16. Common List Mistakes

❌ Avoid

  • Using random paragraphs instead of lists
  • Using lists only for visual indentation
  • Incorrect nesting
  • Leaving out list item elements
  • Using excessive nested lists

✅ Use

  • Semantic list elements
  • Logical grouping
  • Proper nesting
  • CSS for visual styling
  • Lists when information is genuinely list-like

📚 19. Quick Reference

Element / Attribute Purpose
<ul> Creates an unordered list
<ol> Creates an ordered list
<li> Creates a list item
<dl> Creates a description list
<dt> Defines a description term
<dd> Provides a description or details
type Specifies ordered-list numbering style
start Specifies the starting number of an ordered list
reversed Reverses the numbering of an ordered list
list-style-type Controls list marker appearance with CSS

⭐ 20. List Best Practices

  • Use <ul> when item order does not matter.
  • Use <ol> when sequence matters.
  • Use <dl> for terms and corresponding descriptions.
  • Place individual items inside <li>.
  • Use proper nesting for multi-level lists.
  • Use CSS to control visual appearance.
  • Use semantic HTML rather than creating fake lists with paragraphs.
  • Keep lists organized and easy to understand.
