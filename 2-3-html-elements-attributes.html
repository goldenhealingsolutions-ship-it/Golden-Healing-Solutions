2.3 — HTML Elements & Attributes

Learn how HTML elements create the structure of a webpage and how attributes provide additional information and functionality.

🎯 Learning Objectives

By the end of this lesson, you should be able to:

  • Define an HTML element.
  • Identify opening and closing tags.
  • Explain the difference between elements and tags.
  • Identify HTML attributes.
  • Explain the purpose of attributes.
  • Use attributes correctly.
  • Identify global attributes.
  • Use common HTML attributes such as id, class, and title.
  • Use link and image attributes such as href and src.
  • Understand Boolean attributes.
  • Create properly structured HTML elements.

📖 1. What Is an HTML Element?

An HTML element is a complete piece of HTML that represents content or structure on a webpage.

Elements are created using HTML tags and may contain text, other elements, attributes, or a combination of these.

Example 
<p>
    Welcome to my website.
</p>

The entire structure above is a paragraph element.

🏷️ 2. HTML Tags vs. HTML Elements

HTML Tag

A tag is the markup used to create an element. 

<p>

HTML Element

An element includes the opening tag, content, and closing tag when applicable. 

<p>
    Hello World
</p>
Remember:

A tag is part of an HTML element. An element is the complete structure.

🔓 3. Opening and Closing Tags

Many HTML elements have an opening tag and a closing tag. 

<h1>
    Welcome
</h1>

The opening tag is: 

<h1>

The closing tag contains a forward slash: 

</h1>

⚡ 4. Void Elements

Some HTML elements do not contain content and do not require closing tags. These are commonly called void elements.

Element Purpose
<img> Displays an image.
<br> Creates a line break.
<hr> Represents a thematic break.
<input> Creates a form input.
<meta> Provides metadata.
<link> Connects external resources. 
<img src="photo.jpg" alt="A beautiful landscape">

<br>

<hr>

<input type="text">

⚙️ 5. What Is an HTML Attribute?

An attribute provides additional information about an HTML element.

Attributes are normally placed inside the opening tag. 

<p class="intro">
    Welcome to my website.
</p>

In this example:

  • <p> is the HTML element.
  • class is the attribute.
  • "intro" is the attribute value.

🔍 6. Anatomy of an Attribute

<a   href ="https://example.com" >
    Visit Website
</a>

Part Example Purpose
Element <a> Creates a hyperlink.
Attribute href Specifies the destination.
Attribute Value "https://example.com" Provides the destination address.

🧰 7. Common HTML Attributes

id

Uniquely identifies an element within a page. 

<p id="intro">
    Welcome
</p>

class

Assigns an element to one or more classes. 

<p class="highlight">
    Important
</p>

title

Provides additional advisory information. 

<p title="More information">
    Hover over me
</p>

style

Applies inline CSS styling. 

<p style="color: gold;">
    Hello
</p>

lang

Specifies the language of an element or document. 

<p lang="en">
    Hello
</p>

hidden

Indicates that an element is not currently relevant or displayed. 

<p hidden>
    Hidden content
</p>

🆔 8. The id Attribute

The id attribute provides a unique identifier for an HTML element. 

<h1 id="main-title">
    Golden Healing Solutions
</h1>

An ID should generally be unique within a document.

Example:

JavaScript can use an ID to find a specific element. 

document.getElementById("main-title");

🏷️ 9. The class Attribute

The class attribute assigns an element to one or more classes. Classes are commonly used with CSS and JavaScript. 

<p class="intro">
    Welcome to our website.
</p>

<p class="intro">
    Learn web development.
</p>

Multiple elements can use the same class. 

<p class="text gold">
    Welcome
</p>

An element can also have multiple classes separated by spaces.

🔗 10. The href Attribute

The href attribute specifies the destination of a hyperlink. 

<a href="https://example.com">
    Visit Website
</a>

Links can also point to another page on your own website. 

<a href="about.html">
    About Us
</a>

🖼️ 11. The src and alt Attributes

The src attribute specifies the location of an image. The alt attribute provides alternative text describing the image. 

<img
    src="logo.png"
    alt="Golden Healing Solutions logo"
>
Accessibility Best Practice

Use meaningful alternative text for informative images. This helps users who rely on screen readers and also provides useful information when an image cannot load.

☑️ 12. Boolean Attributes

Boolean attributes represent a true/false condition. When a Boolean attribute is present, it is generally considered enabled. 

<input type="checkbox" checked>

<input type="text" disabled>

<button disabled>
    Submit
</button>
Attribute Meaning
checked Checkbox or radio control is selected.
disabled Form control is disabled.
required Form control must be completed.
readonly Value cannot normally be edited by the user.
multiple Allows multiple selections where supported.

📋 13. Multiple Attributes

An HTML element can contain multiple attributes. 

<input
    type="text"
    id="username"
    class="form-input"
    placeholder="Enter your username"
    required
>

Each attribute provides additional information about the element.

Important:

Separate attributes with spaces. Do not place multiple attributes together without spaces.

🔤 14. Attribute Values and Quotes

Attribute values are normally written inside quotation marks. 

<p class="intro">
    Welcome
</p>

Double quotation marks are the standard convention. Single quotation marks can also be used in HTML. 

<p class='intro'>
    Welcome
</p>
Best Practice:

Choose one quotation style and use it consistently throughout your project.

🪆 15. Attributes and Nested Elements

Attributes belong to the element in whose opening tag they are written. 

<section id="about">

    <h2 class="section-title">
        About Us
    </h2>

    <p class="description">
        Learn more about our company.
    </p>

</section>

Here:

  • The section has an id.
  • The h2 has a class.
  • The p has a class.

✅ 16. Writing Valid HTML

❌ Incorrect 

<p class="intro" id="text">

Welcome

</div>

The opening element and closing element do not match.

✅ Correct 

<p
    class="intro"
    id="text"
>

    Welcome

</p>

The opening and closing tags match.

💻 17. Hands-On Practice

Build an Accessible Profile Card

Create a profile card using HTML. Your card should contain:

  • An image.
  • Alternative text.
  • A heading.
  • A paragraph.
  • A link.
  • At least one class attribute.
  • At least one id attribute.
  • At least one additional attribute.
Practice Starter 
<section id="profile-card" class="profile">

    <img
        src="profile.jpg"
        alt="Profile photograph"
    >

    <h2 class="profile-name">
        Your Name
    </h2>

    <p class="profile-description">
        Write a short description about yourself.
    </p>

    <a
        href="contact.html"
        class="profile-link"
    >
        Contact Me
    </a>

</section>

🌎 18. Real-World Example

Consider a button on a website: 

<button
    id="submitButton"
    class="primary-button"
    type="submit"
    title="Submit your application"
>

    Submit Application

</button>

This single element contains several attributes.

Attribute Purpose
id Uniquely identifies the button.
class Allows CSS or JavaScript to target the button.
type Defines the type of button.
title Provides additional information.
