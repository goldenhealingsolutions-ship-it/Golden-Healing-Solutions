QUESTION 01 OF 10

What is the primary purpose of Visual Studio Code?

Correct Answer: B

Visual Studio Code is a source-code editor commonly used by developers to create and modify HTML, CSS, JavaScript, and many other types of code.
QUESTION 02 OF 10

What should you create before beginning a new webpage project?

Correct Answer: A

A project folder keeps the files associated with your website organized in one location.
QUESTION 03 OF 10

Which file extension is commonly used for an HTML webpage?

Correct Answer: C

HTML documents commonly use the .html file extension.
QUESTION 04 OF 10

Which application should you use to view an HTML webpage as a user would see it?

Correct Answer: A

Web browsers such as Chrome, Edge, Firefox, and Safari interpret HTML and display webpages.
QUESTION 05 OF 10

Which HTML declaration identifies the document as an HTML5 document?

Correct Answer: B

The <!DOCTYPE html> declaration tells the browser that the document uses the modern HTML document standard.
QUESTION 06 OF 10

You changed your HTML file but do not see the changes in the browser. What should you check first?

Correct Answer: B

When developing webpages, save your changes and refresh the browser so it can load the updated version of the file.
QUESTION 07 OF 10

Which sequence represents a basic beginner web development workflow?

Correct Answer: A

A basic workflow is to create or edit code, save the file, open or refresh the webpage in a browser, and test the result.
QUESTION 08 OF 10

What is Git primarily used for in software development?

Correct Answer: A

Git is a distributed version-control system. It allows developers to track changes to files and collaborate on projects.
QUESTION 09 OF 10

What is GitHub commonly used for?

Correct Answer: A

GitHub is a platform commonly used to host Git repositories and support collaboration, code review, project management, and related development workflows.
QUESTION 10 OF 10

Which of the following represents a properly organized beginner website project?

Correct Answer: A

Keeping website files inside an organized project folder makes development easier to manage as the project grows.
