2.10 — Semantic HTML

Learn how to structure webpages using meaningful HTML elements that clearly communicate the purpose of each section to browsers, developers, search engines, and assistive technologies.

🎯 Learning Objectives

By the end of this lesson, you should be able to:

  • Define semantic HTML.
  • Explain why semantic HTML is important.
  • Identify common semantic HTML elements.
  • Use <header> correctly.
  • Use <nav> for navigation.
  • Use <main> for primary page content.
  • Use <section> to organize related content.
  • Use <article> for self-contained content.
  • Use <aside> for related secondary content.
  • Use <footer> for footer information.
  • Understand the difference between semantic and non-semantic elements.
  • Build a properly structured semantic webpage.

📖 1. What Is Semantic HTML?

Semantic HTML means using HTML elements that clearly describe the meaning and purpose of their content.

For example:

Non-Semantic 

<div class="header">
    Website Header
</div>

The <div> element does not tell the browser what the content represents.

Semantic 

<header>
    Website Header
</header>

The <header> element communicates the purpose of the content.

🌟 2. Why Semantic HTML Matters

♿ Accessibility

Semantic elements help assistive technologies understand the structure of a webpage.

🔎 SEO

Meaningful page structure can help search engines better understand webpage content.

👩‍💻 Developer Experience

Semantic HTML makes code easier for developers to read, maintain, and understand.

🏗️ Page Structure

Semantic elements create a logical structure for webpages.

🏠 3. The <header> Element

The <header> element represents introductory content for a webpage or section.

Example 
<header>

    <h1>
        Golden Healing Solutions
    </h1>

    <p>
        Web Development Bootcamp
    </p>

</header>
Remember:

A page can have a header, and individual sections or articles can also have their own headers.

🧭 4. The <nav> Element

The <nav> element identifies a major navigation section. 

<nav>

    <a href="index.html">
        Home
    </a>

    <a href="courses.html">
        Courses
    </a>

    <a href="contact.html">
        Contact
    </a>

</nav>
Best Practice:

Use <nav> for significant navigation areas, not necessarily every individual link on a webpage.

📄 5. The <main> Element

The <main> element contains the primary content of the webpage. 

<main>

    <h1>
        Web Development Bootcamp
    </h1>

    <p>
        Learn professional web development.
    </p>

</main>
Important:

A document should normally have one primary <main> element.

📚 6. The <section> Element

The <section> element represents a thematic group of related content. 

<section>

    <h2>
        HTML Fundamentals
    </h2>

    <p>
        Learn the fundamentals of HTML.
    </p>

</section>
Tip:

A section will often have a heading that describes its topic.

📰 7. The <article> Element

The <article> element represents self-contained content that could potentially stand on its own.

Examples include:

  • Blog posts
  • News articles
  • Forum posts
  • Product reviews
  • Course announcements
<article>

    <h2>
        5 Tips for Learning HTML
    </h2>

    <p>
        HTML is the foundation of the web...
    </p>

</article>

📌 8. The <aside> Element

The <aside> element contains content that is related to, but not part of, the primary content. 

<aside>

    <h2>
        Related Courses
    </h2>

    <ul>

        <li>
            CSS Fundamentals
        </li>

        <li>
            JavaScript Fundamentals
        </li>

    </ul>

</aside>

🔻 9. The <footer> Element

The <footer> element contains footer information for a page or section. 

<footer>

    <p>
        © 2026 Golden Healing Solutions
    </p>

    <a href="contact.html">
        Contact Us
    </a>

</footer>

🖼️ 10. <figure> and <figcaption>

The <figure> element is used for self-contained content such as images, diagrams, illustrations, or code examples.

The <figcaption> element provides a caption. 

<figure>

    <img
        src="html-diagram.jpg"
        alt="HTML document structure">

    <figcaption>
        Basic HTML document structure.
    </figcaption>

</figure>

⏰ 11. The <time> Element

The <time> element represents a specific time or date. 

<p>

    The course begins on

    <time datetime="2026-09-01">
        September 1, 2026
    </time>

</p>

🖍️ 12. The <mark> Element

The <mark> element represents text that is highlighted or marked for reference. 

<p>

    The most important concept is

    <mark>
        semantic structure
    </mark>.

</p>

📂 13. <details> and <summary>

These elements create an expandable section without requiring JavaScript. 

<details>

    <summary>
        What is HTML?
    </summary>

    <p>
        HTML stands for HyperText Markup Language.
    </p>

</details>
Click to see the example

HTML stands for HyperText Markup Language and is used to structure content on webpages.

⚖️ 14. Semantic vs. Non-Semantic Elements

Semantic

  • <header>
  • <nav>
  • <main>
  • <section>
  • <article>
  • <aside>
  • <footer>
  • <figure>

Non-Semantic

  • <div>
  • <span>

Non-semantic elements are still useful when no more meaningful semantic element fits the purpose.

📦 15. When Should You Use <div>?

The <div> element is a generic container. 

<div class="card">

    <h2>
        Course Information
    </h2>

    <p>
        Learn web development.
    </p>

</div>
Best Practice:

Do not avoid <div> completely. Use semantic elements when they accurately describe the content. Use <div> when a generic container is appropriate.

🔤 16. The <span> Element

The <span> element is a generic inline container. 

<p>

    Learn

    <span class="highlight">
        HTML
    </span>

    fundamentals.

</p>

♿ 19. Semantic HTML & Accessibility

Semantic HTML is an important part of creating accessible websites.

Screen readers and other assistive technologies can use semantic landmarks to help users navigate a webpage.

For example, a screen reader can identify the <main>, <nav>, <header>, and <footer> areas of a page.

🔎 20. Semantic HTML & SEO

Semantic HTML helps provide meaningful structure that makes webpage content easier for search engines and other software to interpret.

For example, using: 

<article>

    <h2>
        How to Learn HTML
    </h2>

    <p>
        HTML is the foundation of the web.
    </p>

</article>

communicates more meaning than placing all of the same content inside generic <div> elements.

⭐ 22. Semantic HTML Best Practices

✅ Do

  • Use meaningful HTML elements.
  • Use headings to organize content.
  • Use <nav> for major navigation.
  • Use <main> for primary content.
  • Use <article> for self-contained content.
  • Use <section> for thematic groups.
  • Use semantic elements whenever appropriate.

❌ Avoid

  • Using <div> for everything.
  • Using headings only for visual size.
  • Creating unnecessary landmarks.
  • Using semantic elements incorrectly.
  • Ignoring accessibility.

🎓 25. Lesson Summary

Semantic HTML gives webpages meaningful structure.

Instead of using generic containers for everything, developers can use elements such as <header>, <nav>, <main>, <section>, <article>, <aside>, and <footer> to communicate what different areas of a webpage represent.

Semantic HTML is an important part of professional web development because it improves organization, accessibility, maintainability, and the ability of software to interpret webpage structure.
