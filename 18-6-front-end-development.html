18.6 — Front-End Development

Build the front end of your Capstone project using HTML, CSS, and JavaScript.

🎯 Learning Objectives

  • Translate your wireframe into a functional webpage.
  • Build semantic HTML page structures.
  • Apply the UI design system using CSS.
  • Create responsive layouts.
  • Add client-side interactivity using JavaScript.
  • Create functional navigation and forms.
  • Organize front-end project files professionally.
  • Test the interface across different screen sizes.

📖 What Is Front-End Development?

Front-end development is the process of building the part of a website or web application that users see and interact with.

Your Capstone should now move from the planning stages into actual development.

You will use HTML to structure content, CSS to style and lay out the interface, and JavaScript to add behavior and interactivity. :contentReference[oaicite:1]{index=1}

📁 1. Project File Structure

Organize your project files so another developer can easily understand your code.

my-capstone-project/
├── index.html
├── about.html
├── contact.html
├── services.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
│   ├── logo.png
│   └── images...
└── README.md
Best Practice: Keep HTML, CSS, JavaScript, images, and other assets organized rather than placing everything into one file.
