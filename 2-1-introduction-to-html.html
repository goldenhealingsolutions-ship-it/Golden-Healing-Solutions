2.1 — Introduction to HTML

Learn the foundation of every modern web page: HTML — HyperText Markup Language.

🎯 Learning Objectives

By the end of this lesson, you should be able to:

  • Explain what HTML is.
  • Explain the purpose of HTML in web development.
  • Identify HTML elements and tags.
  • Understand HTML attributes.
  • Create a basic HTML document.
  • Explain the difference between HTML elements and tags.
  • Use headings, paragraphs, links, and images.
  • Understand the basic structure of an HTML5 page.
  • Create a simple web page using HTML.

📖 1. What Is HTML?

HTML stands for HyperText Markup Language.

HTML is the standard markup language used to structure content on web pages.

HTML tells the browser what different pieces of content represent.

Think of HTML as the structure of a website.

If a website were a house, HTML would represent the structure: walls, doors, rooms, windows, and other structural components.

🧩 2. HTML, CSS & JavaScript

🏗️ HTML

HTML provides the structure and content.

Examples:

  • Headings
  • Paragraphs
  • Images
  • Links
  • Forms

🎨 CSS

CSS controls presentation and appearance.

Examples:

  • Colors
  • Fonts
  • Spacing
  • Layouts
  • Animations

⚙️ JavaScript

JavaScript adds behavior and interactivity.

Examples:

  • Buttons
  • Interactive menus
  • Calculations
  • Dynamic content
  • Form validation

🌐 The Complete Website

HTML + CSS + JavaScript work together to create modern interactive websites.

🏷️ 3. HTML Tags

HTML uses tags to identify and structure different types of content.

Most HTML elements use an opening tag and a closing tag.

Example 
<p>This is a paragraph.</p>

In this example:

  • <p> is the opening tag.
  • This is a paragraph. is the content.
  • </p> is the closing tag.

🧱 4. HTML Elements

An HTML element generally consists of an opening tag, content, and a closing tag. 

<h1>Welcome to My Website</h1>

<p>
This is my first web page.
</p>

The complete structure makes each piece of content an HTML element.

⚙️ 5. HTML Attributes

Attributes provide additional information about an HTML element.

Attributes are placed inside the opening tag. 

<a href="https://example.com">
Visit Example
</a>

Here:

  • <a> creates a link.
  • href is an attribute.
  • The URL is the attribute value.

📄 6. Basic HTML5 Document Structure 

<!DOCTYPE html>

<html lang="en">

<head>

    <meta charset="UTF-8">

    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">

    <title>My Website</title>

</head>

<body>

    <h1>Hello World</h1>

    <p>
        Welcome to my website.
    </p>

</body>

</html>
Element Purpose
<!DOCTYPE html> Declares that the document uses HTML5.
<html> Root element of the document.
<head> Contains document metadata and resources.
<title> Defines the browser/page title.
<body> Contains the visible page content.

🧰 7. Common HTML Elements

Element Purpose Example
<h1> Main heading <h1>Welcome</h1>
<p> Paragraph <p>Hello</p>
<a> Link <a href="...">Link</a>
<img> Image <img src="image.jpg">
<ul> Unordered list <ul>...</ul>
<ol> Ordered list <ol>...</ol>
<li> List item <li>Item</li>
<button> Button <button>Click</button>

🔠 8. HTML Headings

HTML provides six heading levels: 

<h1>Main Heading</h1>

<h2>Section Heading</h2>

<h3>Subsection</h3>

<h4>Heading 4</h4>

<h5>Heading 5</h5>

<h6>Heading 6</h6>
Important:

Use headings to create a logical document structure. Do not choose heading levels simply because they look bigger or smaller.

🔗 9. Creating Links

The <a> element creates hyperlinks. 

<a href="https://example.com">
Visit Example
</a>

The href attribute specifies where the link should take the user.

🖼️ 10. Adding Images 

<img
    src="images/logo.png"
    alt="Golden Healing Solutions logo">
Why is alt text important?

The alt attribute provides a text description of the image. It helps users who rely on assistive technologies and can also provide information if the image cannot be displayed.

🪆 11. HTML Nesting

HTML elements can be placed inside other elements. This is called nesting. 

<div>

    <h2>About Me</h2>

    <p>
        Welcome to my website.
    </p>

</div>

The <h2> and <p> elements are nested inside the <div>.

🏛️ 12. Semantic HTML

Semantic HTML uses elements that communicate the meaning or purpose of their content.

Element Purpose
<header> Introductory content or page header.
<nav> Navigation links.
<main> Main page content.
<section> Thematic section of content.
<article> Self-contained content.
<footer> Footer information.
